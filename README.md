# Pro Algorithm Live

איש המכירות מנהל שיחת Zoom, Meet או Teams עם לקוח. המערכת מקשיבה לשני הצדדים ומתמללת בעברית. כל שתי דקות Claude בונה ומעדכן את **תוכנית העבודה**: אותה מצגת של 6 עמודים כמו ב-Canva, בלי מחירים ובלי שעות. התוכנית מוצגת בקישור ציבורי שמתעדכן לבד.

```
desktop/   אפליקציית Windows (Electron) → קובץ התקנה EXE
web/       השרת והדף הציבורי (Next.js) → עולה ל-Vercel
```

## איך זה עובד

1. האפליקציה רצה ברקע ליד השעון. כשהמיקרופון נדלק ב-Zoom, Teams או בדפדפן, קופצת התראה "נראה שאתה בשיחה".
2. לוחצים "התחל להקשיב לשיחה". נוצר קישור ציבורי, והוא מועתק אוטומטית ללוח.
3. האפליקציה מקליטה את **המיקרופון** (איש המכירות) ואת **סאונד המחשב** (הלקוח), ושולחת לשרת קטע כל 15 שניות לתמלול. קטעים שקטים לא נשלחים.
4. כל 2 דקות, או בלחיצה על "עדכן עכשיו", Claude מעדכן את התוכנית. הדף הציבורי מתעדכן תוך כמה שניות, והחלקים שהשתנו מסומנים לרגע בצהוב.
5. איש המכירות רואה באפליקציה פאנל פרטי שהלקוח לא רואה: שאלות לשאול עכשיו, איפה ה-ROI וסיכונים. אפשר גם לכתוב הערה ל-AI, למשל "הלקוח רוצה להתחיל מהצעות המחיר".
6. "סיים שיחה" מייצר גרסה סופית. אותו קישור נשאר, והמתכנת מקבל אותו. אפשר לשמור את הדף כ-PDF עם Ctrl+P, עמוד אחד לכל שקף.

## העלאה ל-Vercel (פעם אחת)

1. מעלים את התיקייה ל-GitHub ופותחים פרויקט חדש ב-Vercel. ב-**Root Directory** בוחרים `web`.
2. ב-Vercel: **Storage → Marketplace → Upstash for Redis → Connect**. משתני הגישה נוספים לבד.
3. ב-**Settings → Environment Variables** מוסיפים:

   | משתנה | ערך |
   |---|---|
   | `APP_TOKEN` | מחרוזת ארוכה ואקראית. אותה מחרוזת תוזן באפליקציה |
   | `ANTHROPIC_API_KEY` | מפתח מ-console.anthropic.com |
   | `STT_PROVIDER` | `openai`, `elevenlabs` או `gemini` |
   | `OPENAI_API_KEY` | אם הספק הוא openai |
   | `ELEVENLABS_API_KEY` | אם הספק הוא elevenlabs |
   | `GEMINI_API_KEY` | אם הספק הוא gemini (aistudio.google.com) |

4. Deploy. מקבלים כתובת, למשל `https://proalgo-live.vercel.app`. כדאי לבדוק את `/demo` שם.

## קובץ ההתקנה

הקובץ המוכן נמצא ב-`desktop/dist/ProAlgorithmLive-Setup-1.0.0.exe`.

**אפשרות א', הכי פשוטה לאיש המכירות:** לפני הבנייה ממלאים ב-`desktop/config.defaults.json` את `serverUrl` ואת `appToken`, ואז בונים מחדש:

```powershell
cd desktop; npm install; npm run dist
```

**אפשרות ב':** מתקינים את הקובץ הקיים, ובפתיחה הראשונה ממלאים בחלון ההגדרות (⚙) את כתובת השרת ואת קוד הגישה.

ההתקנה היא לחיצה כפולה, בלי מנהל מערכת. האפליקציה עולה עם Windows ונשארת ליד השעון. בהתקנה הראשונה Windows SmartScreen עשוי להזהיר, כי הקובץ לא חתום. לוחצים "More info → Run anyway". אם רוצים להיפטר מהאזהרה צריך תעודת חתימת קוד.

## הרצה מקומית לפיתוח

```powershell
cd web; copy .env.example .env.local; npm install; npm run dev
```

```powershell
cd desktop; npm install; npm start
```

- בלי Redis השרת שומר בזיכרון, וזה מתאים רק לפיתוח.
- בדיקת הקלטה אוטומטית: `npm start -- --selftest` מקליט 20 שניות, שולח לשרת ומדפיס דוח.

## הערות

- **עלויות:** כל עדכון של Claude שולח את כל התמלול עד אותו רגע. בשיחה של שעה זה בערך 30 עדכונים, וחלק מהתמלול נשמר במטמון. התמלול מחויב לפי דקות אודיו אצל הספק שבחרתם.
- **מודל:** `claude-opus-5-5` עם effort `medium`. אפשר לשנות דרך `CLAUDE_MODEL` ו-`CLAUDE_EFFORT`. אם Claude מסרב לבקשה, היא עוברת אוטומטית למודל גיבוי (server-side fallback).
- **פרטיות:** הקישור הציבורי מציג רק את התוכנית. התמלול והפאנל הפרטי זמינים רק עם `APP_TOKEN`. מומלץ לומר ללקוח בתחילת השיחה שהיא מתומללת.
- **אוזניות:** בלי אוזניות המיקרופון קולט גם את הלקוח מהרמקולים, ואז התמלול כפול. Claude מסתדר עם זה, אבל עם אוזניות התמלול נקי יותר.
- **העיצוב:** הרקעים ב-`web/public/slides` יוצאו מעותק של המצגת ב-Canva, בלי הטקסטים. כל תיבת טקסט ממוקמת בדיוק כמו במקור (`web/components/Deck.tsx`). ב-Canva נשאר עותק בשם "רקעים ל-Canva Live". אפשר למחוק אותו.
