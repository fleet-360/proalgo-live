# Pro Algorithm Live

איש המכירות מנהל שיחת Zoom, Meet או Teams עם לקוח. המערכת מקשיבה לשני הצדדים ומתמללת בעברית, ובערך כל שתי דקות Claude בונה ומעדכן את **תוכנית העבודה**: אותה מצגת של 6 עמודים כמו ב-Canva, בלי מחירים ובלי שעות. התוכנית מוצגת בקישור ציבורי שמתעדכן לבד.

```
desktop/   אפליקציית Windows (Electron) → קובץ התקנה EXE
web/       השרת והדף הציבורי (Next.js) → Vercel
```

**כתובת השרת:** https://proalgo-live.vercel.app (דף לדוגמה: `/demo`)
**קוד:** https://github.com/fleet-360/proalgo-live (מאגר ציבורי; אין בו מפתחות ואין פרטי לקוחות)

## איך זה עובד בשיחה

1. האפליקציה רצה ברקע ליד השעון. כשהמיקרופון נדלק ב-Zoom, Teams או בדפדפן, קופצת התראה "נראה שאתה בשיחה". **לחיצה על ההתראה מתחילה להקשיב מיד.** אפשר גם לפתוח את האפליקציה וללחוץ "התחל להקשיב לשיחה".
2. נוצר קישור ציבורי לתוכנית, והוא מועתק ללוח. משתפים מסך עם הקישור ומראים ללקוח.
3. האפליקציה מקליטה את **המיקרופון** (איש המכירות) ואת **סאונד המחשב** (הלקוח), ושולחת קטע כל 20 שניות לתמלול. קטעים שקטים לא נשלחים.
4. כל 2 דקות, או בלחיצה על "עדכן עכשיו", Claude מעדכן את התוכנית. הדף מתעדכן תוך שניות, והחלקים שהשתנו מסומנים לרגע.
5. באפליקציה יש פאנל קצר שרק איש המכירות רואה: עד 3 שאלות לשאול עכשיו, איפה ה-ROI, וסיכון אמיתי אם יש. אפשר לכתוב **הערה ל-AI** ("הלקוח רוצה להתחיל מהביטולים"), והיא נכנסת לתוכנית בעדכון הבא.
6. "סיים שיחה" מכין גרסה סופית. אותו קישור נשאר, והמתכנת מקבל אותו. שמירה כ-PDF: Ctrl+P, עמוד לכל שקף.

**מה המערכת עושה לבד כדי שהשיחה לא תיפגע:**
- אם האינטרנט נופל לרגע, הקטעים נשמרים ונשלחים שוב כשהחיבור חוזר.
- אם האוזניות מתנתקות או ה-Bluetooth נופל, האפליקציה מתחברת מחדש בעצמה.
- אם סאונד המחשב לא נקלט, מופיעה הודעה בולטת עם כפתור "נסה שוב".
- אם Zoom נסגר ואיש המכירות שכח ללחוץ "סיים", מופיעה תזכורת אחרי דקה.
- יציאה מהאפליקציה באמצע שיחה מסיימת קודם את השיחה ומכינה גרסה סופית.
- טעויות תמלול מתוקנות בשקט. מחירים, שעות ולוחות זמנים נחסמים גם בקוד, לא רק בהנחיה ל-AI.
- בטלפון הקישור מציג את התוכנית כטקסט קריא במקום שקפים קטנים.

## קובץ ההתקנה

`desktop/dist/ProAlgorithmLive-Setup-1.1.0.exe`. כתובת השרת וקוד הגישה כבר בפנים, אז אין צורך להגדיר כלום.

- ההתקנה היא לחיצה כפולה, בלי מנהל מערכת. האפליקציה עולה עם Windows ונשארת ליד השעון.
- בהתקנה הראשונה Windows SmartScreen יזהיר, כי הקובץ לא חתום: **More info → Run anyway**.
- בפעם הראשונה Windows עשוי לבקש אישור גישה למיקרופון.
- כדאי לעבוד עם אוזניות. בלי אוזניות המיקרופון קולט גם את הלקוח, והמערכת מנקה את הכפילויות אבל פחות טוב.

**בנייה מחדש** (למשל אחרי החלפת קוד הגישה): הכתובת והקוד נמצאים ב-`desktop/config.build.json`, שלא עולה ל-GitHub.

```powershell
cd desktop; npm install; npm run dist
```

## השרת ב-Vercel

- פרויקט `proalgo-live`, תיקייה `web`. כל push ל-`main` מעלה גרסה חדשה לבד.
- אחסון: Upstash Redis (חינמי), מחובר לפרויקט.
- משתני סביבה: `APP_TOKEN`, `ANTHROPIC_API_KEY`, `STT_PROVIDER=gemini`, `GEMINI_API_KEY`. אפשר לעבור ל-`openai` או `elevenlabs` עם המפתח המתאים.
- **החלפת קוד הגישה:** משנים את `APP_TOKEN` ב-Vercel, מעדכנים את `desktop/config.build.json` ובונים מחדש את קובץ ההתקנה.
- **תוכנית Vercel:** החשבון במסלול Hobby, שמיועד לשימוש לא מסחרי. לשימוש קבוע של החברה כדאי לעבור ל-Pro.

## תמלול

ספק ברירת המחדל הוא Gemini (`gemini-3.5-transcribe`). במסלול הנוכחי של Google הוא מוגבל ל-10 בקשות בדקה. לכן כשנגמרת המכסה השרת עובר לבד ל-`gemini-3.5-flash-lite`, שמתמלל באותה איכות. כדי לא להגיע למגבלה בשיחות במקביל, כדאי להעלות את חשבון Google למסלול גבוה יותר.

## הרצה מקומית לפיתוח

```powershell
cd web; copy .env.example .env.local; npm install; npm run dev
```

```powershell
cd desktop; npm install; npm start
```

- בלי Redis השרת שומר בזיכרון, וזה מתאים רק לפיתוח.
- בדיקת הקלטה אוטומטית: `npm start -- --selftest` מקליט 25 שניות, שולח לשרת ומדפיס דוח.
- ניסויי הנחיות: `node web/scripts/prompt-lab.mjs <scenarios.json> <name> <turns>` מריץ את ההנחיה האמיתית על תמלול לדוגמה.

## הערות

- **עלויות:** כל עדכון של Claude שולח את התמלול, וחלק גדול ממנו נקרא מהמטמון (prompt caching) במחיר מופחת. בשיחה של שעה יש בערך 30 עדכונים. התמלול ב-Gemini עולה בערך 0.003 דולר לדקה.
- **מודל:** `claude-opus-5-5`, effort `medium`. אפשר לשנות דרך `CLAUDE_MODEL` ו-`CLAUDE_EFFORT`.
- **פרטיות:** הקישור הציבורי מציג רק את התוכנית. התמלול והפאנל הפרטי זמינים רק עם `APP_TOKEN`. מומלץ לומר ללקוח בתחילת השיחה שהיא מתומללת.
- **העיצוב:** הרקעים ב-`web/public/slides` יוצאו מעותק של המצגת ב-Canva בלי הטקסטים, וכל תיבת טקסט ממוקמת כמו במקור (`web/components/Deck.tsx`). העותק "רקעים ל-Canva Live" ב-Canva כבר לא נחוץ.
